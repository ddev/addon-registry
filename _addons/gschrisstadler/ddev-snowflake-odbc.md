# DDEV Snowflake ODBC

## Overview

This add-on adds the Snowflake Database ODBC Driver for PHP.

## Installation

```bash
ddev add-on get gschrisstadler/ddev-snowflake-odbc
ddev restart
```

After installation, make sure to commit the `.ddev` directory to version control.
